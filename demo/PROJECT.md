# Project

## Overview

This is a minimal Python utility demo for validating AI Project Harness Mini's context recovery, scope control, and verification rules.

## Goal

Implement and maintain a set of tested, simple mathematical utility functions.

## Tech Stack

- Python 3
- Python standard library `unittest`

## Architecture

- `src/` contains implementation code.
- `tests/` contains automated tests.
- `PROJECT.md`, `STATE.md`, and `TASK.md` contain the Harness project state.

## Constraints

- Keep the demo minimal.
- Do not introduce third-party dependencies.
- The current task must follow `TASK.md`.
- Mark a task complete only after real verification succeeds.
